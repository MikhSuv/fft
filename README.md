# Быстрое преобразование Фурье

## Сборка

```sh
cmake -B build
cmake --build build -j
```
Компилятор должен поддерживать стандарт f2018.
Если `gfortran` по умолчанию не поддерживает его и есть компилятор,
который его поддерживает (например `gfortran-12`), нужно явно указать компилятор:
``` 
cmake -B build -DCMAKE_Fortran_COMPILER=gfortran-12
``` 

Создается исполнимый файл `./build/fft` и тесты.
Команда для запуска тестов:
```
ctest --test-dir build
```

## Использование

```
./build/fft [data.dat] [result.dat] [abs.dat] [inverse|-i|--inverse]
```
Команда без аргументов выполнит прямое преобразование Фурье для исходных данных из
`data.dat` и запишет результат в `result.dat`,
а модули результата запишет в `abs.dat`.

С аргументом `inverse`, `-i` или `--inverse` программа выполнит обратное преобразование, независимо от позиции аргумента.
Нестандартные имена файлов можно указать как позиционные аргументы в следующем порядке: исходные данные, результат и модули результата.
